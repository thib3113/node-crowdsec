## Questions and bug reports

Open an issue on GitHub:

<https://github.com/thib3113/node-crowdsec/issues>

Use the bug report or feature request template. Please include the package and
version, your Node.js version, and the steps to reproduce.

## Security

Do not open a public issue for a vulnerability. See [SECURITY.md](./SECURITY.md)
for private reporting.

## Commercial support

No commercial support is offered. The project is maintained on a best-effort
basis.
