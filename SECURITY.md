# Security Policy

## Supported Versions

Security fixes are provided for the latest released version and for the `main`
branch. Older versions are not supported.

## Reporting a Vulnerability

**Please do not open a public issue for a security vulnerability.**

Use GitHub's private vulnerability reporting:

<https://github.com/thib3113/node-crowdsec/security/advisories/new>

If private reporting is unavailable, contact the maintainer at
[thib3113@gmail.com](mailto:thib3113@gmail.com).

Please include:

- the affected package and version;
- steps to reproduce, with a minimal example;
- the impact you expect;
- a possible fix, if you have one.

You will get an initial response as soon as possible. Please allow time for a
fix before public disclosure.
